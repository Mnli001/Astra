# Astra Tarot

Монгол хэл дээрх таро ба зурхайн тайлалын вэбсайт. Төрсөн өдрөөр орд, монгол жил, амьдралын замын тоог тооцоолж, 22 хөзрөөс гурвыг сонгоход тайлал болон одон орны бодит огноотой 90 хоногийн төлөвлөгөө гаргана.

## Файлууд

| Файл | Юу вэ |
|---|---|
| `index.html` | Нүүр хуудас |
| `app.html` | Тайлал хийдэг апп: профайл, хөзөр сонгох, тайлал, QPay төлбөр, татах файлууд |
| `privacy.html`, `terms.html` | Нууцлал, үйлчилгээний нөхцөл |
| `assets/cards/` | 22 хөзрийн зураг (SVG) |
| `assets/astra/sky.js` | Нүүр хуудсанд өнөөдрийн сар болон ирэх 90 хоногийн огноог тооцоолно |
| `assets/` бусад | Загварын систем, хөдөлгөөн, эффектүүд |

## Компьютер дээр ажиллуулах

Модуль скрипт ашигладаг тул файлыг шууд нээхгүй, жижиг сервер ашиглана:

```bash
python -m http.server 8000
```

Дараа нь хөтчөөр `http://localhost:8000` хаягийг нээнэ.

## Нийтлэхээс өмнө

- **QPay:** `app.html` доторх `API_CONFIG.mode`-г `"production"` болгож, `createInvoiceUrl` ба `verifyPaymentUrl`-д өөрийн серверийн хаягийг оруулна. Одоо демо горимд байгаа тул төлбөр жинхэнээр татагдахгүй.
- **Домэйн:** `index.html`-ийн толгой хэсэгт `canonical` холбоосыг нээж, `astratarot.mn`-ийг өөрийн домэйноор солино.
- **И-мэйл:** `support@astratarot.example` гэсэн түр хаягийг жинхэнэ хаягаар солино.
- **Одон орны огноо:** хиртэлт, гаригийн ухралтын жагсаалт 2028 оны эхэн хүртэл. Жил бүр `assets/astra/sky.js` болон `app.html` доторх `SKY_EVENTS`-ийг шинэчилнэ.

Хиртэлтийн огноо: timeanddate.com. Буд, Ангараг, Сугар гаригийн ухралт: Old Farmer's Almanac. Цагаан сарын огноо: Wikipedia. Сарны үеийг Meeus-ийн одон орны томьёогоор тооцоолдог.
